TEMPLATE UNDANGAN DIGITAL PREMIUM - GRATIS & TANPA WATERMARK

EDIT DATA:
1. Buka config.js.
2. Ganti groom, bride, tanggal, orang tua, lokasi, rekening, WhatsApp.
3. Masukkan foto ke folder images dengan nama:
   hero.jpg
   quote.jpg
   pria.jpg
   wanita.jpg
   foto1.jpg sampai foto6.jpg
4. Untuk musik, masukkan MP3 ke images lalu ubah:
   music:"images/musik.mp3"

CEK:
- Buka index.html di browser.
- Jika sudah sesuai, upload seluruh folder ke GitHub Pages atau Netlify.

CATATAN:
Template menggunakan Google Fonts dari internet. Foto placeholder yang tersedia dapat diganti dengan foto asli Anda.
